FarmWise - Sustainable Agriculture

Setup:
1. Install Node.js (LTS).
2. Extract this ZIP.
3. Open a terminal in the extracted project folder (the folder containing package.json).
4. Run: npm install
5. Run: npm run dev

Security note: the original .env file was intentionally excluded because it may contain private API keys or credentials. If the application requires environment variables, create a local .env file and add your own values. Never share real API keys.
